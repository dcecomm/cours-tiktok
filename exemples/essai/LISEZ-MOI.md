# L'essai

`essai.m4a` sert à une seule chose : vérifier, après l'installation, que toute la chaîne marche sur
l'ordinateur (transcription, coupe, sous-titres, image, montage, livraison).

```bash
node outils/verifier.mjs --essai
```

C'est une voix de synthèse qui dit : « Bonjour. Ceci est un essai. Si vous entendez cette voix et
lisez ces mots, tout fonctionne. » Elle n'est là que pour ce test. Dans un vrai short, il n'y
a jamais de voix de synthèse : seulement la sienne.
